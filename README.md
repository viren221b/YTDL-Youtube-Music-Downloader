# ytdl-ver-1.1

A CLI tool/script to download YouTube videos as mp3.

## Dependencies
- Python 3
- ffmpeg (install via your package manager)
- deno (install via your package manager)

## Installation
1. git clone <your repo>
2. pip install -r requirements.txt
3. chmod +x yt-music-dl-main.py
4. sudo ln -s /path/to/ytdl-ver-1-1.py /usr/local/bin/ytdl

## Usage
Just type `ytdl` in your terminal.

## updates:
ver 1.1: added a chapter split feature for yt videos that have split chapters

## Supported Systems
- This python script is mainly made for linux users, so you might wanna add linux sub-system for windows or mac if you're in that respective operating systems.
